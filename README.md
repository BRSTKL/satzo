# Satzo (web app)

Satzo'nun telefon sürümü: kısa video klipleriyle dil öğrenme akışı. Adres: https://brstkl.github.io/satzo/

iPhone'da Safari ile aç, Paylaş → Ana Ekrana Ekle.

`data.json` klip listesini ve altyazıları içerir. Satzo Chrome eklentisinde Editör modu açıkken akış sayfasındaki
"Telefon için altyazıları hazırla" düğmesiyle üretilir ve bu klasöre konur.
